# Superpowers

This folder holds the technical designs and implementation plans written by the [Superpowers](https://github.com/obra/superpowers) plugin, in one folder per change named after its branch, `<issue-number>-<short-slug>/`, which contains `design.md` and `plan.md`. Business specs live in [openspec/](../openspec/), and decisions live in [docs/explanation/decisions/](../docs/explanation/decisions/README.md).
